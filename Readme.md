# 💖 Valentine Week 2026 💖

A beautifully designed multi-page **Valentine’s Week website** celebrating 7 days of love and romance.  
Each day has its own dedicated page with unique styling, animations, and interactive elements.

🌐 **Live Website:**  
```bash
https://valentine-anshukhandelwal.netlify.app/
```
---

## ✨ Features

- ❤️ 7 dedicated Valentine Week pages  
  - Rose Day  
  - Propose Day  
  - Chocolate Day  
  - Teddy Day  
  - Promise Day  
  - Hug Day  
  - Kiss Day  
  - Valentine’s Day
- 🎨 Unique CSS design for each day
- 🧩 Clean and modular folder structure
- ⚡ Interactive elements using JavaScript
- 📱 Responsive design for desktop & mobile
- 🚀 Deployed on Netlify
- 🔗 Smooth navigation between all pages

---

## 🛠️ Tech Stack

- **HTML5**
- **CSS3**
- **JavaScript (Vanilla JS)**
- **Git & GitHub**
- **Netlify (Deployment)**

## 🚀 Deployment

The project is deployed using **Netlify** with the following settings:

- **Branch:** `main`
- **Publish directory:** `pages`
- **Build command:** Not required (static site)
